# hack---tracker

## About
A task tracker project built for hackathon using Flask and SQLite. Users can add tasks and track their progress.

## Features
- Add new tasks
- Track task progress  
- SQLite database integration

## Tech Stack
- Python
- Flask
- SQLite

## How to Run
1. `pip install flask`
2. `python app.py`
3. Open `http://localhost:5000` in browser
